One AMPLS per DNSAMPLS endpoints like api.monitor.azure.com are global. A second AMPLS + PE on networks sharing this resolver overwrites the first one's records.
Blob moves with AMPLSThe AMPLS PE writes into privatelink.blob.core.windows.net. Leave that zone on-prem and agents lose solution-pack downloads.
Forward public, not privatelinkForwarder = blob.core.windows.net, then delete the local privatelink.* zone. A leftover local zone is more specific and wins.
No Azure zones outboundThe resolver ruleset forwards only on-prem names. Add blob.core.windows.net there and you build a loop with on-prem.
Open first, PrivateOnly lastPrivateOnly blocks every network on this DNS from any workspace not in the AMPLS, in any subscription or tenant.
NewPrivatePath rowsPEs with no on-prem record today resolve public. After cutover they go private, so check ER routes and NSGs first.
